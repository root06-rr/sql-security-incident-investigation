# My SQL learning notes

This folder connects the SQL concepts in my Notion notes to selected original screenshots exported from that page. I collected these notes while studying the Google Cybersecurity Certificate on Coursera and working through TryHackMe labs.

The screenshots are selected examples from the learning material. They are not screenshots of the four investigations in this repository, and they are not presented as proof that the project SQL was executed.

## Selected screenshots

- [Table structure with DESCRIBE](screenshots/01-table-structure.jpg): table fields, types, keys, nullability, and extra attributes.
- [Reading selected columns](screenshots/02-select-columns.jpg): using SELECT and FROM to retrieve specific fields.
- [Grouping and counting records](screenshots/03-group-by-count.jpg): using COUNT() with GROUP BY.
- [Aggregate function example](screenshots/04-aggregate-sum.jpg): using SUM() to calculate a total.

The complete topic explanations are in the [SQL reference](../sql-reference.md). The original Notion page remains the source for the full set of notes and screenshots.

## How these notes connect to the project

The investigation scripts apply a subset of the concepts to the supplied sample database. The screenshots illustrate learning examples from the notes. I keep these two things separate so that a learning screenshot is not mistaken for output from a project investigation.
