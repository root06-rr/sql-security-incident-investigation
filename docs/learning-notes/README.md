# My SQL learning notes

This folder connects the SQL concepts in my Notion notes to the learning material behind this project. I collected these notes while studying the Google Cybersecurity Certificate on Coursera and working through TryHackMe labs.

The original Notion export contains 29 screenshots. I reviewed them and identified useful examples covering table structure, SELECT queries, grouping and counting, filtering, string functions, and aggregate functions.

The screenshots are not included in this repository yet. The available GitHub file-writing connection supports text files but did not provide a reliable way to add the original binary image files in this update. I have not created replacement images or used placeholders.

## Screenshot selection plan

When the original image files are added, I will use a small selection rather than copying all 29 screenshots:

- A DESCRIBE result showing table fields, types, keys, nullability, and extra attributes.
- A SELECT result showing how specific columns are retrieved.
- A GROUP BY and COUNT() result.
- A filtering example using the clauses and operators covered in the notes.
- A string function example.
- Aggregate function examples using COUNT(), SUM(), MAX(), and MIN().

The screenshots should remain examples from the learning notes. They must not be labelled as output from the four investigations in this repository.

The complete topic explanations are in the [SQL reference](../sql-reference.md). The original [Notion page](https://app.notion.com/p/19-SQL-301f055fceba8052a846cdbf4c8fce16?source=copy_link) remains the source for the full set of notes and screenshots.
