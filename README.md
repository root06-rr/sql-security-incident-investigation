# SQL-Based Security Access and Asset Audit

I built this project to practise reviewing authentication activity and auditing employee and hardware records with SQL. It uses simulated records from my SQL learning material. It is not connected to a live environment and does not represent a real security incident.

## Project objectives

- Review failed authentication attempts by account.
- Identify login activity after 18:00.
- Filter authentication records by country and IP pattern.
- Review employee patch information.
- Compare user records with asset assignments.

## Investigations

1. Authentication review
2. After-hours access review
3. IP and location review
4. Endpoint and asset audit

## Scope

The records are sample data. Documentation IP ranges are used to demonstrate filtering and are not threat intelligence. Query matches are not proof of malicious activity.

## Skills

SQL filtering, Boolean logic, pattern matching, aggregation, joins, null handling, and database setup.
